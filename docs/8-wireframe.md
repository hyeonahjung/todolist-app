## 1. 공통 컴포넌트

### 1.1 PC 헤더 네비게이션 (인증 후)

```
+-------------------------------------------------------------------------------------------+
|  TodoListApp                              [할일 목록]  [카테고리]  [홍길동 ▼]  [로그아웃]  |
+-------------------------------------------------------------------------------------------+
                                                                    |
                                                              +-----+----------+
                                                              | 개인정보 수정   |
                                                              | 회원 탈퇴      |
                                                              +----------------+
```

- "TodoListApp" 로고 클릭 시 할일 목록 화면으로 이동
- "[홍길동 ▼]" 클릭 시 드롭다운 메뉴 표시 (USER.name 표시)
- 활성 메뉴 항목은 하이라이트 처리

### 1.2 모바일 헤더 네비게이션 (인증 후)

```
+------------------------------------------+
|  TodoListApp                    [≡ 메뉴]  |
+------------------------------------------+

/* 메뉴 열린 상태 (햄버거 메뉴 펼침) */
+------------------------------------------+
|  TodoListApp                    [X 닫기]  |
+------------------------------------------+
|  홍길동 님                                |
+------------------------------------------+
|  > 할일 목록                              |
|  > 카테고리 관리                           |
|  > 개인정보 수정                           |
|  > 로그아웃                               |
|  > 회원 탈퇴                              |
+------------------------------------------+
```

### 1.3 PC 헤더 (비인증 상태)

```
+-------------------------------------------------------------------------------------------+
|  TodoListApp                                                  [로그인]  [회원가입]         |
+-------------------------------------------------------------------------------------------+
```

### 1.4 공통 알림 토스트 메시지

```
/* 성공 알림 */
+------------------------------------------+
|  [v]  수정이 완료되었습니다.        [X]   |
+------------------------------------------+

/* 오류 알림 */
+------------------------------------------+
|  [!]  이미 사용 중인 이메일입니다.   [X]  |
+------------------------------------------+

/* 경고 알림 */
+------------------------------------------+
|  [~]  세션이 만료되었습니다. 재로그인이   |
|       필요합니다.                   [X]   |
+------------------------------------------+
```

## 2. 화면 1 — 로그인 (SC-02)

**목적**: 가입된 사용자가 이메일과 비밀번호로 인증하여 서비스에 접근한다.
**관련 UC**: UC-02, UC-03
**액터**: 비인증 사용자 (가입 완료 상태)

### PC 레이아웃

```
+-------------------------------------------------------------------------------------------+
|  TodoListApp                                                  [로그인]  [회원가입]         |
+-------------------------------------------------------------------------------------------+
|                                                                                           |
|                          +------------------------------+                                 |
|                          |         로그인               |                                 |
|                          |                              |                                 |
|                          |  이메일 (email)              |                                 |
|                          |  [___________________________]                                 |
|                          |                              |                                 |
|                          |  비밀번호 (password)         |                                 |
|                          |  [___________________________]                                 |
|                          |                              |                                 |
|                          |  [!] 이메일 또는 비밀번호가  |  <- 오류 상태 (E-01, E-04)      |
|                          |      올바르지 않습니다.      |                                 |
|                          |                              |                                 |
|                          |  [       로그인       ]      |                                 |
|                          |                              |                                 |
|                          |  계정이 없으신가요?          |                                 |
|                          |  [회원가입 바로가기]          |                                 |
|                          +------------------------------+                                 |
|                                                                                           |
+-------------------------------------------------------------------------------------------+
```

### 모바일 레이아웃

```
+------------------------------------------+
|  TodoListApp                    [≡ 메뉴]  |
+------------------------------------------+

|                                          |
|  이메일 (email)                          |
|  [____________________________________]  |
|                                          |
|  비밀번호 (password)                     |
|  [____________________________________]  |
|                                          |
|  [!] 이메일 또는 비밀번호가              |

|  [           로그인              ]       |
|                                          |
|  계정이 없으신가요?                      |
|  [       회원가입 바로가기        ]      |

```

### 인터랙션 설명

| 사용자 액션 | 시스템 반응 |
|------------|-----------|
| "로그인" 버튼 클릭 (정상 입력) | JWT Access Token + Refresh Token 발급 후 할일 목록 화면으로 이동 |
| "로그인" 버튼 클릭 (인증 실패) | [E-01] 인라인 오류 메시지: "이메일 또는 비밀번호가 올바르지 않습니다." |
| "로그인" 버튼 클릭 (필드 미입력) | [E-04] 미입력 필드 하단에 "이 필드는 필수입니다." 표시 |
| "회원가입 바로가기" 클릭 | 회원가입 화면으로 이동 |

## 3. 화면 2 — 회원가입 (SC-01)

**목적**: 신규 사용자가 이름, 이메일, 비밀번호를 입력하여 계정을 생성한다.
**관련 UC**: UC-01
**액터**: 비인증 사용자 (신규 방문자)

### PC 레이아웃

```
+-------------------------------------------------------------------------------------------+
|  TodoListApp                                                  [로그인]  [회원가입]         |
+-------------------------------------------------------------------------------------------+
|                                                                                           |
|                          +------------------------------+                                 |
|                          |         회원가입             |                                 |
|                          |                              |                                 |
|                          |  이름 (name)                 |                                 |
|                          |  [___________________________]                                 |
|                          |  최소 1자, 최대 50자          |                                 |
|                          |                              |                                 |
|                          |  이메일 (email)              |                                 |
|                          |  [___________________________]                                 |
|                          |  [!] 이미 사용 중인 이메일입니다.  <- E-02                     |
|                          |                              |                                 |
|                          |  비밀번호 (password)         |                                 |
|                          |  [___________________________]                                 |
|                          |  영문자·숫자 각 1자 이상, 8~64자 |                            |
|                          |  [!] 비밀번호 규칙 미충족    |  <- E-03                        |
|                          |                              |                                 |
|                          |  [       가입하기       ]    |                                 |
|                          |                              |                                 |
|                          |  이미 계정이 있으신가요?     |                                 |
|                          |  [로그인 바로가기]           |                                 |
|                          +------------------------------+                                 |
|                                                                                           |
+-------------------------------------------------------------------------------------------+
```

### 모바일 레이아웃

```
+------------------------------------------+
|  TodoListApp                    [≡ 메뉴]  |
+------------------------------------------+
|                                          |
|            회원가입                      |
|                                          |
|  이름 (name)                            |
|  [____________________________________]  |
|  최소 1자, 최대 50자                     |
|  [!] 이름을 입력해 주세요.              |
|                        <- E-04           |
|                                          |
|  이메일 (email)                          |
|  [____________________________________]  |
|  [!] 올바른 이메일 형식을 입력해 주세요. |
|                        <- E-01           |
|                                          |
|  비밀번호 (password)                     |
|  [____________________________________]  |
|  영문자·숫자 각 1자 이상, 8~64자        |
|  [!] 비밀번호는 8자 이상이어야 합니다.  |
|                        <- E-03           |
|                                          |
|  [          가입하기             ]      |
|                                          |
|  이미 계정이 있으신가요?                 |
|  [        로그인 바로가기        ]      |
|                                          |
+------------------------------------------+
```

### 인터랙션 설명

| 사용자 액션 | 시스템 반응 |
|------------|-----------|
| "가입하기" 버튼 클릭 (정상 입력) | 계정 생성 + 기본 카테고리(일반, 업무, 개인) 자동 부여 후 로그인 화면으로 이동, 성공 토스트 표시 |
| "가입하기" 버튼 클릭 (이메일 형식 오류) | [E-01] "올바른 이메일 형식을 입력해 주세요." 인라인 오류 표시 |
| "가입하기" 버튼 클릭 (이메일 중복) | [E-02] "이미 사용 중인 이메일입니다." 인라인 오류 표시 |
| "가입하기" 버튼 클릭 (비밀번호 규칙 미충족) | [E-03] "비밀번호는 8자 이상, 영문자와 숫자를 각 1자 이상 포함해야 합니다." 표시 |
| "가입하기" 버튼 클릭 (이름 누락/초과) | [E-04] 해당 필드 하단에 오류 메시지 표시 |
| "로그인 바로가기" 클릭 | 로그인 화면으로 이동 |

## 4. 화면 3 — 할일 목록 (SC-10)

**목적**: 인증된 사용자가 자신의 할일 전체를 조회하고 카테고리/완료 여부/종료예정일 기간으로 필터링한다.
**관련 UC**: UC-12, UC-11, UC-10
**액터**: 인증된 사용자
**기본 정렬**: created_at 내림차순

### PC 레이아웃

```
+-------------------------------------------------------------------------------------------+
|  TodoListApp                              [할일 목록]  [카테고리]  [홍길동 ▼]  [로그아웃]  |
+-------------------------------------------------------------------------------------------+
|                                                                                           |
|  +-----------------------------+  +------------------------------------------------------+|
|  |  필터                       |  |  할일 목록                    [+ 할일 추가]          ||
|  |-----------------------------|  |------------------------------------------------------||
|  |  카테고리 (category)        |  |                                                      ||
|  |  [전체 ▼]                   |  |  +--------------------------------------------------+||
|  |   - 전체                    |  |  |  [x] is_completed  업무                          |||
|  |   - 일반                    |  |  |  헬스장 PT 등록하기  title                        |||
|  |   - 업무                    |  |  |  설명: 집 근처 헬스장... description              |||
|  |   - 개인                    |  |  |  due_date: 2026-05-25        [수정]  [삭제]       |||
|  |   - 운동                    |  |  +--------------------------------------------------+||
|  |   - ...                     |  |                                                      ||
|  |                             |  |  +--------------------------------------------------+||
|  |  완료 여부 (is_completed)   |  |  |  [ ] is_completed  개인                          |||
|  |  ( ) 전체                   |  |  |  병원 예약하기  title                             |||
|  |  ( ) 미완료                 |  |  |  설명: (없음)                                    |||
|  |  ( ) 완료                   |  |  |  due_date: 2026-05-30        [수정]  [삭제]       |||
|  |                             |  |  +--------------------------------------------------+||
|  |  종료예정일 (due_date)      |  |                                                      ||
|  |  시작: [__________]         |  |  +--------------------------------------------------+||
|  |  종료: [__________]         |  |  |  [x] is_completed  일반                          |||
|  |                             |  |  |  회의 자료 준비  title                            |||
|  |  [  필터 적용  ]            |  |  |  설명: 2분기 실적 자료  description               |||
|  |  [  필터 초기화  ]          |  |  |  due_date: (없음)            [수정]  [삭제]       |||
|  +-----------------------------+  |  +--------------------------------------------------+||
|                                   |                                                      ||
|                                   |  /* 빈 상태 (E-01) */                                ||
|                                   |  +--------------------------------------------------+||
|                                   |  |                                                  |||
|                                   |  |   조건에 맞는 할일이 없습니다.                   |||
|                                   |  |   [+ 할일 추가하기]                              |||
|                                   |  |                                                  |||
|                                   |  +--------------------------------------------------+||
|                                   +------------------------------------------------------+|
+-------------------------------------------------------------------------------------------+
```

### 모바일 레이아웃

```
+------------------------------------------+
|  할일 목록               [+ 할일 추가]   |
```

### 할일 카드 상태별 표시

```
/* 미완료 할일 카드 */
+--------------------------------------------------+
|  [ ] is_completed=false      카테고리명           |
|  할일 제목 (title)                                |
|  설명 요약 (description, 2줄 제한)               |
|  종료예정일: due_date    [수정 버튼]  [삭제 버튼] |
+--------------------------------------------------+

/* 완료 할일 카드 (취소선 + 흐리게) */
+--------------------------------------------------+
|  [x] is_completed=true       카테고리명           |
|  ~~할일 제목 (title)~~                            |
|  설명 요약 (description)                          |
|  종료예정일: due_date    [수정 버튼]  [삭제 버튼] |
+--------------------------------------------------+

/* 마감 임박 카드 (due_date <= 오늘+3일) */
+--------------------------------------------------+
|  [ ] is_completed=false      카테고리명           |
|  할일 제목 (title)                                |
|  [!] 종료예정일: 2026-05-14 (마감 임박)          |
|                         [수정 버튼]  [삭제 버튼]  |
+--------------------------------------------------+
```

### 인터랙션 설명

| 사용자 액션 | 시스템 반응 |
|------------|-----------|
| 카드의 체크박스 [ ] 클릭 | is_completed 토글 (미완료 → 완료) 즉시 반영 |
| 카드의 체크박스 [x] 클릭 | is_completed 토글 (완료 → 미완료) 즉시 반영 |
| 카드 제목 클릭 | 할일 상세 화면으로 이동 |
| "[수정]" 버튼 클릭 | 할일 수정 화면으로 이동 |
| "[삭제]" 버튼 클릭 | 삭제 확인 다이얼로그 표시 |
| "[+ 할일 추가]" 클릭 | 할일 등록 화면으로 이동 |
| 카테고리 드롭다운 선택 | 해당 카테고리 필터 즉시 적용 |
| "[필터 초기화]" 클릭 | 모든 필터 해제 후 전체 목록 표시 |
| 필터 조건에 해당 없음 | [E-01] "조건에 맞는 할일이 없습니다." 빈 상태 표시 |

## 5. 화면 4 — 할일 등록 (SC-05)

**관련 UC**: UC-08
**액터**: 인증된 사용자

### PC 레이아웃

```
+-------------------------------------------------------------------------------------------+
|  TodoListApp                              [할일 목록]  [카테고리]  [홍길동 ▼]  [로그아웃]  |
+-------------------------------------------------------------------------------------------+
|                                                                                           |
|                     +----------------------------------------+                           |
|                     |  새 할일 등록                          |                           |
|                     |----------------------------------------|                           |
|                     |                                        |                           |
|                     |  제목 (title) *필수                    |                           |
|                     |  [______________________________________]                          |
|                     |  최소 1자, 최대 100자                  |                           |
```
