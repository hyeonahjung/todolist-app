## 시나리오별 상세 결과

### SC-01: 신규 회원가입
- **기본 흐름**: 이름/이메일/비밀번호 입력 후 가입하기 → HTTP 201 Created ✅
- **E-01 이메일 형식 오류**: (유효성 검사 브라우저 레벨 처리)
- **E-02 이메일 중복**: 동일 이메일 재가입 시 "이미 사용 중인 이메일입니다." 표시 → HTTP 409 Conflict ✅
- **E-03 비밀번호 규칙**: 빈 폼 제출 시 인라인 오류 메시지 표시 ✅
- **E-07 카테고리 미선택**: (SC-05 할일 등록에서 검증)
- **스크린샷**: sc01-01-initial.png, sc01-02-register-form.png, sc01-04-duplicate-email-error.png

### SC-02: 로그인 및 로그아웃
- **E-01 로그인 실패**: 잘못된 자격증명 → HTTP 401 Unauthorized ✅
- **기본 흐름 (로그인)**: 올바른 자격증명 입력 → HTTP 200 OK, 메인 화면 이동 ✅
- **기본 흐름 (로그아웃)**: 로그아웃 버튼 클릭 → 로그인 화면 리다이렉트 ✅
- **스크린샷**: sc02-01-login-success.png, sc02-02-logout-success.png

### SC-03: 개인 정보 수정
- **A-01 이름만 수정**: "테스트유저" → "테스트유저수정" 저장 → HTTP 200 OK ✅
- **UI 즉시 반영**: 네비게이션 바 사용자 이름 즉시 갱신 ✅
- **스크린샷**: sc03-01-profile-updated.png

### SC-04: 회원 탈퇴
- **경고 메시지**: "주의: 탈퇴 시 내 계정, 카테고리, 할일이 즉시 삭제되며 복구할 수 없습니다." 표시 ✅
- **A-01 취소**: 취소 시 탈퇴 중단, 프로필 화면 유지 ✅
- **E-01 비밀번호 불일치**: 잘못된 비밀번호 → HTTP 400 Bad Request ✅
- **기본 흐름**: 올바른 비밀번호 입력 후 탈퇴 → 로그인 화면 이동 ✅
- **사후 조건 검증**: 탈퇴 계정으로 로그인 시도 → HTTP 401 Unauthorized ✅
- **스크린샷**: sc04-01-withdrawal-form.png

### SC-05: 카테고리 등록 + 할일 등록
- **기본 카테고리 확인**: 일반, 업무, 개인 기본 카테고리 존재 + 수정/삭제 불가 표시 ✅
- **카테고리 생성**: "운동" 카테고리 생성 → HTTP 201 Created ✅
- **E-01 중복 카테고리**: 동일 이름 재생성 → HTTP 409 Conflict ✅
- **E-03 할일 제목 누락**: "제목을 입력해 주세요." 인라인 오류 ✅
- **E-07 카테고리 미선택**: "카테고리를 선택해 주세요." 인라인 오류 ✅
- **할일 등록**: "헬스장 등록하기" (운동 카테고리, 2026-05-20) → HTTP 201 Created ✅
- **스크린샷**: sc05-01-category-created.png, sc05-02-todo-form.png, sc05-03-todo-created.png

### SC-06: 카테고리 수정
- **기본 흐름**: 수정 버튼 클릭 시 현재 이름 채워진 폼 표시 ✅
- **수정 완료**: "운동" → "헬스" 저장 → HTTP 200 OK, 목록 즉시 반영 ✅
- **스크린샷**: sc06-01-category-renamed.png

### SC-07: 카테고리 삭제 및 할일 자동 이동
- **확인 메시지**: "헬스 카테고리를 삭제하시겠습니까? 소속 할일은 '일반' 카테고리로 이동됩니다." ✅
- **A-02 취소**: 취소 시 카테고리 유지 ✅
- **기본 흐름**: 삭제 확인 → HTTP 200 OK ✅
- **사후 조건**: "헬스장 등록하기" 할일이 "일반" 카테고리로 자동 이동 확인 ✅
- **스크린샷**: sc07-01-delete-confirm.png, sc07-02-todo-moved-to-general.png

### SC-08: 할일 수정 및 완료 처리
- **수정 폼**: 현재 데이터 채워진 상태로 폼 표시 ✅
- **수정 완료**: "헬스장 등록하기" → "헬스장 PT 등록하기", 날짜 변경 → HTTP 200 OK ✅
- **완료 처리**: 완료 버튼 클릭 시 "완료 취소 ✓" 버튼으로 변경 ✅
- **A-01 역방향 토글**: "완료 취소" 클릭 시 미완료 상태로 복원 ✅
- **스크린샷**: sc08-01-todo-updated-toggle.png

### SC-09: 할일 삭제
- **삭제 확인**: '"프로젝트 보고서 작성" 할일을 삭제하시겠습니까?' 확인 다이얼로그 ✅
- **A-01 취소**: 취소 시 할일 유지 ✅
- **기본 흐름**: 삭제 확인 → HTTP 200 OK, 목록에서 즉시 제거 ✅

### SC-10: 할일 목록 조회 및 필터링
- **카테고리 필터**: "업무" 선택 → "프로젝트 보고서 작성"만 표시 ✅
- **복합 필터**: 업무 + 완료 → "조건에 맞는 할일이 없습니다." ✅ (E-01)
- **A-01 필터 초기화**: 필터 초기화 버튼 → 전체 목록 복원 ✅
- **스크린샷**: sc10-01-filter-no-result.png

### SC-11: 할일 상세 조회
- **라우팅**: /todos/{id} URL로 이동 ✅
- **전체 필드 표시**: 제목, 카테고리, 설명, 종료예정일, 완료여부, 등록일시 모두 표시 ✅
- **목록 복귀**: "< 할일 목록으로" 링크 동작 ✅
- **스크린샷**: sc11-01-todo-detail.png
