## 전체 유스케이스 다이어그램

```mermaid
graph LR
    %% 액터 정의
    Guest(["👤 비인증 사용자"])
    AuthUser(["👤 인증된 사용자"])
    System(["⚙️ 시스템"])

    %% 사용자 인증 영역
    subgraph AUTH["🔐 사용자 인증"]
        direction TB
        UC01("UC-01\n회원가입")
        UC02("UC-02\n로그인")
        UC03("UC-03\n로그아웃")
        UC04("UC-04\n개인정보 수정")
        UC14("UC-14\n회원 탈퇴")
    end

    %% 카테고리 관리 영역
    subgraph CAT["📁 카테고리 관리"]
        direction TB
        UC05("UC-05\n카테고리 등록")
        UC06("UC-06\n카테고리 수정")
        UC07("UC-07\n카테고리 삭제")
    end

    %% 할일 관리 영역
    subgraph TODO["✅ 할일 관리"]
        direction TB
        UC08("UC-08\n할일 등록")
        UC09("UC-09\n할일 수정")
        UC10("UC-10\n할일 삭제")
        UC11("UC-11\n할일 완료 처리")
        UC12("UC-12\n할일 목록 조회")
        UC13("UC-13\n할일 상세 조회")
    end

    %% 비인증 사용자 → 인증
    Guest -->|실행| UC01
    Guest -->|실행| UC02

    %% 인증된 사용자 → 인증
    AuthUser -->|실행| UC03
    AuthUser -->|실행| UC04
    AuthUser -->|실행| UC14

    %% 인증된 사용자 → 카테고리
    AuthUser -->|실행| UC05
    AuthUser -->|실행| UC06
    AuthUser -->|실행| UC07

    %% 인증된 사용자 → 할일
    AuthUser -->|실행| UC08
    AuthUser -->|실행| UC09
    AuthUser -->|실행| UC10
    AuthUser -->|실행| UC11
    AuthUser -->|실행| UC12
    AuthUser -->|실행| UC13

    %% 시스템 처리
    System -.->|"«extend»\n할일을 기본 카테고리로 이동"| UC07
    System -.->|"«extend»\n연관 데이터 일괄 삭제"| UC14
    System -.->|"«extend»\n기본 카테고리 제공"| UC08
```

## 도메인 영역별 상세 다이어그램

### 1. 사용자 인증

```mermaid
graph LR
    Guest(["👤 비인증 사용자"])
    AuthUser(["👤 인증된 사용자"])
    System(["⚙️ 시스템"])

    UC01("UC-01\n회원가입")
    UC02("UC-02\n로그인")
    UC03("UC-03\n로그아웃")
    UC04("UC-04\n개인정보 수정")
    UC14("UC-14\n회원 탈퇴")

    JWTIssue("JWT 토큰 발급")
    DataDelete("연관 데이터 삭제\nCategory · Todo")
    PwdVerify("현재 비밀번호\n확인")

    Guest -->|실행| UC01
    Guest -->|실행| UC02
    AuthUser -->|실행| UC03
    AuthUser -->|실행| UC04
    AuthUser -->|실행| UC14

    UC02 -.->|"«include»"| JWTIssue
    UC04 -.->|"«include»"| PwdVerify
    UC14 -.->|"«include»"| PwdVerify
    System -.->|"«extend»"| DataDelete
    DataDelete -.-> UC14
```

### 2. 카테고리 관리

```mermaid
graph LR
    AuthUser(["👤 인증된 사용자"])
    System(["⚙️ 시스템"])

    UC05("UC-05\n카테고리 등록")
    UC06("UC-06\n카테고리 수정")
    UC07("UC-07\n카테고리 삭제")

    OwnerCheck("소유권 검증\n본인 카테고리 여부")
    DefaultGuard("기본 카테고리 보호\n수정·삭제 차단")
    TodoMove("할일 자동 이동\n→ 기본 카테고리 '일반'")

    AuthUser -->|실행| UC05
    AuthUser -->|실행| UC06
    AuthUser -->|실행| UC07

    UC06 -.->|"«include»"| OwnerCheck
    UC07 -.->|"«include»"| OwnerCheck
    UC06 -.->|"«include»"| DefaultGuard
    UC07 -.->|"«include»"| DefaultGuard
    System -.->|"«extend»\n할일 존재 시"| TodoMove
    TodoMove -.-> UC07
```
